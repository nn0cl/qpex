# 08 — Gauge symmetry (U(1) pedagogy)

## Physics

Local U(1) rotation $\psi(x)\mapsto e^{i\alpha(x)}\psi(x)$ leaves
gauge-invariant observables unchanged when the connection $A_\mu$ transforms
appropriately. Charge density / |\psi|² is the simplest invariant.

## QPex mapping

| Idea | Surface |
|------|---------|
| Matter amplitude label | Discrete site occupation `State` |
| Local phase rotation | `map` tagging a phase bin (stand-in) |
| Invariant observable | occupation / site id via `project`+`measure` |
| Compare before/after | same `measure` support |

Amplitude phases become first-class with complex IR; here the **invariant
occupation** is unchanged under a “gauge map” that only relabels an ancilla.
