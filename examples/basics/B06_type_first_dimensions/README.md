# B06 — Type-First dimensions

Teaches dimensional quantities as **State payloads** (`State<Time>`,
`State<Mass>`, `State<Length>`, `State<Momentum>`) and correlated `evolve` on
phase-space tuples. Terminal leftovers use `measure … tracing_out …`
(ADR 0173) — not ritual `vacuum` rebinds.

Legacy sources: `examples/01_classical_mechanics/phase_space.sqx`,
`examples/05_harmonic_oscillator/classical_oscillator.sqx`.
