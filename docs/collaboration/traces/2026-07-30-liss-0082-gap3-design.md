## Rationale recorded

- A bare integer duplicates `value_id`, which already denotes exactly one
  immutable generation, while asserting a total order the IR neither has nor
  verifies.
- `lineage_id + index` additionally requires defining "lineage" before the
  region graph exists, which would force branching, merging, and hierarchical
  regions into a running number — a direct conflict with the no-eager-flattening
  law.
- Ordering, if it is ever needed, is a property of the producer/consumer region
  graph and therefore belongs to Slice C.
